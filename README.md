# Study Planner v0.8.0

Study Planner 是一个以目标为驱动、可解释、可恢复的动态学习计划系统。v0.8.0 基于完整 v0.7.0 源代码升级，保留计时、完成/部分完成、月历/周历、移动端长按移动、实际用时、游客隔离、Supabase 同步和 iPhone PWA 基线，并把任务创建、目标、日期可用性、计划调整、复盘和计划版本统一到同一套架构中。

## v0.8.0 重点

- **目标系统**：支持期望日期、最晚日期、全部/百分比/数量完成条件、一个任务组关联多个目标、目标自动完成与归档。
- **创建入口分离**：明确区分“添加单项任务”和“创建任务组”；单项任务可归入现有任务组或作为独立任务。
- **先预览后应用**：创建任务、调整目标、修改日期约束、调整任务组规则和接受时长建议，都先生成可解释方案，不静默改写日历。
- **统一调度核心**：新增工作、修复问题、优化未来和广泛重组共用 v0.7 的实际执行、容量、每日上限、手动意图和扰动计算核心。
- **完整方案解释**：所有数量可展开；逐项显示任务、日期、负载、目标、手动安排和拒绝日期原因的前后变化。
- **计划版本**：重大变化保存在本机独立版本存储中，恢复前自动保存当前计划，并保护实际用时和完成记录。
- **复盘与自适应时长**：默认显示简明摘要，按需展开图表；使用最近 10 个有效样本和 IQR 异常值处理，只提出建议，不自动覆盖。
- **统一日期约束**：支持不可用、降容、特殊容量、受保护缓冲日和日期说明，并支持日期范围。
- **可取消计算**：复杂方案在 Web Worker 中计算，可随时取消，不阻塞主界面，也不会留下半应用状态。
- **移动端/PWA**：Today 仍是首页；移除浮动加号；保留七列月历、安全区域、100dvh、底部抽屉和完整换行。

## 技术栈

React 18、TypeScript、Vite、PWA、Supabase、IndexedDB、Recharts。

## 本地运行

```bash
npm install
cp .env.example .env
npm run dev
```

`.env` 示例：

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_xxx
```

浏览器端不得使用 `service_role` 或 `sb_secret_...`。访问日志需要的高权限密钥只能放在服务端环境变量中，并且不能使用 `VITE_` 前缀。

## 验证命令

```bash
npm run typecheck
npm run test:scale
npm run validate:v08
npm run build
```

- `typecheck`：使用项目严格检查配置进行 TypeScript 静态检查。
- `test:scale`：生成 20 个目标、50 个任务组、500 项任务、30 个日期约束和 10 个本地版本的规模夹具。
- `validate:v08`：运行 44 项架构、行为和非功能静态/规模验证。
- `build`：在依赖可正常安装的环境中执行真实 Vite 生产构建。

## 数据与隐私

- 游客计划保存在独立本地命名空间。
- 登录账号使用独立数据空间；不会静默上传已修改的游客计划。
- 首次登录可选择导入游客计划、使用账号演示计划、从空白开始或保持游客数据分离。
- 云端同步只上传当前可移植状态，不上传重型本地计划版本、旧重排快照或冲突备份。
- 完整计划版本历史仅保存在当前设备，设置页会明确提示。
