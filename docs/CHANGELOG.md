# Study Planner 更新日志

本文件保留各版本的迭代记录；产品介绍、架构、运行与验证见根目录 `README.md`。

## v0.9.3

- **修复埋点接口 FUNCTION_INVOCATION_FAILED（访问日志真正进库）**：`/api/visit-log`、`/api/metric-event` 的相对导入补 `.js` 扩展名——Vercel 以 nodenext 编译 api 时无扩展名导入触发 TS2835 且运行时 `ERR_MODULE_NOT_FOUND`，函数启动即崩；修复后生产实测 200/201，访问日志与埋点正常写入。
- **修复登录账号反馈详情 403**：重跑 `supabase-schema.sql` 时 `revoke all` 会抹掉迁移（20260817195500/20260817202500）授予 `authenticated` 的列级 SELECT/UPDATE，导致登录账号反馈全部打不开（游客走 RPC 不受影响）。schema 现与迁移一致并幂等；游客继续只走受控 RPC（不授予 anon 表级 INSERT）。
- **修复桌面 Chromium 窄窗口滚轮滚不动**：移除移动端 `body{overscroll-behavior-y:none}`——Chromium 根滚动链在该规则下吞掉滚轮（实测滚轮事件到达但 scrollY 不动、scrollTo 正常），iOS 触摸滚动不受影响。
- **修复触屏笔记本/Edge 滑动被抢占**：HTML5 原生拖拽仅在纯鼠标桌面启用（`not (any-pointer: coarse)`），并统一门控月历任务卡、折叠面板与重排预览中的拖拽。
- **修复录入排期「未安排项被硬冲突连坐阻塞」**：纯未安排/计划影响类问题不再要求逐项决定，可直接应用（应用后保持未安排）；只有真实硬约束冲突（容量、日期保护、目标、锁定、计时等）保留逐项确认。新增 7 个回归用例。
- **其他**：`ip_geo_cache` 表启用 RLS 并保持与其他服务端专表一致；完整测试套件 17 文件 89 用例全部通过。
- 版本号自 0.9.2 升至 0.9.3。

## v0.9.2

- **修复「开始计时」崩溃（React #426）**：专注计时页为懒加载组件但缺少 Suspense 边界，点击进入时在同步事件里挂起导致整页进入安全模式；现与其它懒加载页面一致，以 Suspense fallback 包裹。
- **修复埋点接口 500**：`/api/visit-log` 与 `/api/metric-event` 不再依赖 `Response.json`（兼容更早的运行时），地理位置解析改为尽力而为兜底，任何未预期异常都以结构化 JSON 返回而非裸 500；补充缺失的 `ip_geo_cache_get/put` 服务端缓存 RPC。
- **修复桌面端（尤其 Edge / 窄窗口）整页滑不动**：弹窗与抽屉的滚动锁改为引用计数，多个弹窗乱序关闭不再把 `body` 锁死；iOS 不受 `overflow:hidden` 影响而桌面 Chromium 会，问题仅出现在桌面端即由此引起。
- 版本号自 0.9.1 升至 0.9.2。

## v0.9.0

- **首次建档与持续录入**：新增可中断、可恢复的录入工作区，支持表头映射、错误行原位修复、批量粘贴和“保存并继续”；录入期间不改动正式计划，也不触发完整排期。
- **教程与导出**：新增带产品截图的教程页，以及统计、月历、任务清单和完整备份导出；侧边栏在桌面端滚动时保持固定。
- **调度性能**：加入稳定输入签名缓存、日期索引、摘要与完整解释拆分，并增加局部交换兜底；最新本机基准中 500 项 P95 约 951ms，低于 1500ms 性能门槛（结果会随设备与负载变化）。
- **算法与时间语义**：增加循环依赖检测、可拆分任务、未来任务移入今天的可控例外；明确历史补录计入所选历史日，今天/未来任务的实际执行计入今天。
- **质量门禁**：补充 Vitest、属性测试、可注入时钟、时区场景、axe 检查、移动端布局审计和 CI 性能阈值。
- **暂缓项**：深色模式、完整全局回溯/Beam Search、跨设备 CAS 合并仍保留在后续迭代计划中。

## v0.8.15

- 修复自定义域名经 Vercel 转发时访问日志可能被误判为跨域而拒绝写入的问题。
- 访问日志改为浏览器持久待发送队列；离线、冷启动或短暂失败后会在联网/重新可见时补写。
- `/api/visit-log` 健康检查现在同时返回已存储页浏览量和累计页浏览量。
- 新增 `/api/visit-log?format=svg`，可在 GitHub README 显示网站累计访问次数。
- 新增 `VISIT_COUNT_OFFSET`，可补入经其他可信来源确认的历史访问基数；不会伪造无法恢复的历史明细。
- 修复历史日期补录实际用时的归属：从今天返回过去日期后保存的用时会计入所选历史日；今天和未来任务的实际执行仍计入今天。
- 统一首页手动记录和计时器结算的日期写入，避免本地凌晨被 UTC 时间误算到前一天。
- 补充 AGPLv3、GitHub 社交预览封面，并修复 validation 验证文件名的中文乱码。

## v0.8.14 过去未完成任务顺延修复

- 修复复盘昨日任务时，未完成任务从过去日期顺延到今天或未来却被误判为“过去日期已冻结”的问题；
- 明确冻结边界：冻结已完成记录、实际执行、锁定和计时上下文，不冻结仍未完成且由用户明确顺延的任务；
- 过去未完成任务可在复盘或“任务 → 待处理”中移到今天/未来，也可转为暂未安排；
- 继续禁止把新计划移入过去日期，并继续保护已完成、锁定和正在计时的任务；
- 新增运行级回归，覆盖复盘顺延、批量移出过去、暂不安排、禁止移入过去及三类不可移动历史。

## v0.8.10 重点

- **计时记录可靠**：活动计时任务从首页完成时先返回统一计时结算；陈旧状态仍会把累计分钟写入实际记录。
- **统计口径可验证**：每日统计抽取为纯函数，时间明细先计、旧版残差只补一次；新增运行级回归。
- **Today 数字统一**：区分原计划、已发生实际、剩余预计和执行负载，容量风险使用真实执行快照。
- **所有任务可找到**：新增具体任务收件箱和待处理、未安排、逾期、今日、未来、已完成、全部视图。
- **重复步骤减少**：批量顺延只保留一个最终确认点；删除直接进入统一预览；批量移动使用日期选择器。
- **恢复先比较**：JSON 导入、云端恢复和同步冲突备份恢复统一显示覆盖差异，并可立即撤销。
- **编辑不再逐字提交**：任务标题与日期备注使用草稿一次保存；时长变化先执行最小作用域预览。
- **高级能力默认折叠**：算法参数、恢复维护、任务组高级规则和目标特殊关联按需展开。
- **复盘暂不顺延仍可找回**：过去未完成任务进入“任务 → 待处理”，Today 同时给出集中入口。

## v0.8.8 重点

- **桌面复杂页面重新编排**：复盘、计划调整入口和方案预览使用独立桌面宽度、正文滚动和粘性底部操作区，不再把所有复杂内容塞进同一种弹窗。
- **复盘信息密度重新平衡**：桌面摘要改为三列两行，避免六张窄卡导致时间数字折行；手机保留两列紧凑摘要和单列任务决策。
- **计划调整主次分区**：桌面左侧表达变化和目标，右侧集中设置今天可接收容量与系统保护；手机自动回落为单列顺序。
- **方案预览渐进展示**：桌面四列摘要、手机两列摘要，推荐方案优先，具体任务、日期、目标和冲突继续按需展开。
- **全局 UI 一致性审计**：目标、统计、设置、任务组、日期约束、历史差异和表单控件统一卡片层级、间距、圆角与响应式重排。

- **复盘当前方案直达**：复盘结束后可直接按用户已选方案顺延，只有主动“获取更多方案”才运行完整候选搜索；也可仅保存复盘。
- **已完成历史不是冲突**：已完成 9 小时、5 套卷子等历史事实保留并计入真实负载，但不再显示为待解决硬冲突，也不阻止其他调整。
- **只处理仍可调整任务**：历史已超载日期若加入新的未完成任务，只针对这些新增或仍可调整任务提供换日、一次性例外或暂不安排。
- **语义化冲突比较**：只拦截新增或恶化的约束事实，既有超载得到改善时不会因提示数字变化被误判。
- **冲突操作分层**：处理任务、修改条件和撤销变化分区展示，允许的选项可因问题类型不同而变化，但含义与后果保持一致。
- **逐项冲突决策**：硬冲突按绝对阻断、用户保护、可一次性放宽、目标/结构冲突分类；每项展示具体任务、数值、后果和可选处理。
- **部分接受后重新计算**：用户可接受部分一次性例外、拒绝其余例外；系统从已选候选继续，只释放被拒绝部分，再次完整预览。
- **最小范围例外**：例外精确到日期、原始规则键、临时上限和涉及任务，不会变成整日或永久授权。
- **手机首页紧凑布局**：Today 头部改为移动端单列 Grid，消除桌面 flex-basis 在纵向布局中造成的大块空白。
- **变化驱动的计划调整协调器**：先判断用户意图是否已经完整，再分流为精确校验、推荐预览、可选优化或探索式优化；不再把所有场景无条件压进四种偏好。
- **用户决定优先**：复盘逐项顺延、批量移动等已经明确的日期只做完整校验；合法项固定不动，冲突时只处理冲突项。
- **推荐优先、多方案后置**：系统准备推荐方案和实质不同的备选，默认只展示推荐；用户可主动比较或继续生成其他方案。
- **任何系统改动先预览**：任务、日期、负载、目标、手动安排、规则例外和结构变化均在应用前展示；应用后创建可恢复版本。
- **外表简洁、内在完整**：第一层显示“发现 5 个问题”等摘要，点击后展开五项问题，再按需查看涉及任务、原因和计算依据。
- **移动端与视觉一致性**：复杂调整使用 100dvh 全屏弹性布局，正文独立滚动；强化选中态，修复大块空白与七列月历宽度；负载增减统一用红绿方向提示。


- **全量对话回归**：再次按 v0.7.0 以来全部确认规则审计，不只检查冻结 MD；补齐完成日期计数、缓冲日轻量规则、日期放宽语义、任务组安全减量、复盘触发和结构变化前后对比。
- **移动入口收敛**：移除 Today 卡片中绕过约束验证的前后移动按钮，任务移动统一进入日历校验或可解释方案。
- **日期容量放宽**：增加容量或解除约束不再被当成必须修复；默认保留当前排期，并提供利用新空间减负的可选方案。
- **目标系统**：支持期望日期、最晚日期、全部/百分比/数量完成条件、一个任务组关联多个目标、目标自动完成与归档。
- **创建入口分离**：明确区分“添加单项任务”和“创建任务组”；单项任务可归入现有任务组或作为独立任务。
- **先预览后应用**：创建任务、调整目标、修改日期约束、调整任务组规则和接受时长建议，都先生成可解释方案，不静默改写日历。
- **统一调度核心**：新增工作、修复问题、优化未来和广泛重组共用 v0.7 的实际执行、容量、每日上限、手动意图和扰动计算核心。
- **完整方案解释**：所有数量可展开；逐项显示任务、日期、负载、目标、手动安排和拒绝日期原因的前后变化。

- **场景级调度纠偏**：目标提前、目标放宽、部分完成 Goal、旅行范围、新任务插入和时长变化均映射为明确变化事件；事件日期不再错误限制调度窗口。
- **计划调整中心重构**：隐藏算法模式到高级范围设置；把问题、移动、日期影响和目标影响收敛为一组可展开摘要；合并“负载对比”和“逐项微调”；合并重复风险列表。
- **结束今天并复盘**：合并原两个入口，统一完成未完成任务处理、复盘记录、完整调整入口和自适应时长建议。
- **计划版本**：重大变化保存在本机独立版本存储中，恢复前自动保存当前计划，并保护实际用时和完成记录。
- **复盘与自适应时长**：默认显示简明摘要，按需展开图表；使用最近 10 个有效样本和 IQR 异常值处理，只提出建议，不自动覆盖。
- **统一日期约束**：支持不可用、降容、特殊容量、受保护缓冲日和日期说明，并支持日期范围。
- **可取消计算**：复杂方案在 Web Worker 中计算，可随时取消，不阻塞主界面，也不会留下半应用状态。
- **移动端/PWA**：Today 仍是首页；移除浮动加号；保留七列月历、安全区域、100dvh、底部抽屉和完整换行。
