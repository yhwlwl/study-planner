# Study Planner v0.8.6 冲突决策与手机首页修复

## 1. 冲突与例外的关系

冲突是约束检测结果；一次性例外只是可放宽冲突的一种解决方式。已完成历史、过去日期和正在计时属于绝对阻断；锁定和日期保护需要用户明确授权；容量、组上限、活动上限、长任务和高强度上限可按最小范围接受一次性例外；目标最晚日期和无可用日期必须通过换日、留为未安排、修改目标或容量处理。

## 2. 决策闭环

```text
严格规则下计算
→ 展示冲突摘要
→ 用户逐项展开并决定
→ 接受项形成最小范围例外
→ 拒绝项释放给调度器
→ 从已选候选继续重新计算
→ 再次展示完整预览
→ 用户最终应用
```

每项例外记录日期、原始规则键、原限制、临时上限和涉及任务。不同任务对同一规则的授权只合并任务并集，不转化为永久规则。

## 3. 按钮状态

- 未处理：`处理 N 个待决定问题`
- 已完成选择：`按这些选择重新计算`
- 可执行：`应用预览中的改动`
- 无候选：提供扩大范围、调整可用时间和调整目标入口

## 4. 手机首页

旧 `.today-hero > div:first-child { flex: 1 1 350px }` 在手机纵向 Flex 中把 350px 解释为高度。v0.8.6 使用响应式 Grid，手机端明确 `height:auto`、`min-height:0`、`flex:none`，操作区紧跟日期摘要。
