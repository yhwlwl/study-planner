# v0.8.1 计划调整中心融合修订说明

## 修订原因

v0.8.0 虽然已经具备完整的调度能力，但计划调整中心仍沿用了 v0.7 的页面骨架，导致用户首先看到“解决当前问题 / 重新组织未来计划”等算法范围选项，而且同一信息在多个区块重复出现：

- 当前问题先完整显示一次，又在“方案后果”里重复；
- 任务数、日期数和保留率先在指标卡出现，又以句子和明细再次重复；
- “修改前后负载”和“逐项微调”分别列出同一批日期；
- “按当前微调结果检查”和“仍需注意”重复显示接近满载等提醒。

## v0.8.1 调整

1. 首屏改为“本次发生了什么”和“当前方案是否仍有非法位置”。
2. repair/full 范围设置移入“调整范围与今日容量”折叠区，不再要求用户先理解算法。
3. 四种方案明确为取舍偏好：少改、均衡、目标、休息。
4. 问题、移动、日期影响、目标预计统一为四个可点击摘要指标。
5. 同一类明细只在一个位置展开，不再同时显示摘要句、后果句和重复列表。
6. “修改前后负载”和“逐项微调”合并为“任务与日期变化”工作台。
7. 单个日期展开后可查看前后任务、原因、影响、拒绝日期原因，并可接受、保留原日、改期、锁定或拖动。
8. 风险统一为“应用前复核”：当前预览的硬风险直接显示，普通负载提醒折叠。
9. 保留今日半冻结、实际执行容量、冻结天数、缓冲日开放、一次性上限例外及预览撤销。
10. 操作文案改为“不应用，关闭 / 应用这个方案”，减少旧“重排”术语。
