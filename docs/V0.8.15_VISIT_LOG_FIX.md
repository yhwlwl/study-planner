# v0.8.15 访问日志与累计访问计数修复

## 问题

旧实现存在两个可靠性缺口：

1. POST 同源判断只比较 `Origin` 与转发 Host；自定义域名经过 Vercel 转发时可能被误判为跨域请求。
2. 前端仅在首次加载时尝试并延迟重试一次；离线、函数冷启动或短暂网络错误后，访问事件会永久丢失。

## 修复

- 同源判断同时接受请求 URL Host、`x-forwarded-host` 与 `host`。
- 页面访问先写入本地持久 outbox，再尝试上传。
- 联网恢复和页面重新可见时自动补写。
- `event_id` 唯一约束继续保证重复重试不会重复计数。
- GET 健康检查返回 `storedPageViews`、`countOffset` 和 `totalPageViews`。
- `?format=svg` 返回可嵌入 GitHub README 的累计访问徽章。
- `VISIT_COUNT_OFFSET` 只用于补入外部可信来源确认的历史基数，不生成伪造明细。

## 数据口径

`totalPageViews = visit_logs 中 page_view 行数 + VISIT_COUNT_OFFSET`

这是网站应用页浏览量，不等于 GitHub 仓库访问者、克隆次数或独立用户数。
