> 对照文档：[PRODUCT_OPTIMIZATION_ROADMAP_V1.md](./PRODUCT_OPTIMIZATION_ROADMAP_V1.md)

## 1. 审查结论

本轮已经完成六个阶段的核心产品改造，并通过本地静态检查、运行时场景检查、调度性能检查、构建和 Bundle 门禁。当前版本可进入 `preview` 分支部署验证。

“完成”在本文中分成两种：

- **代码与本地行为已完成**：功能已经落地，并有自动验证或可复现运行证据。
- **需要真实环境复核**：涉及真实浏览器视口、已配置的 Supabase 项目、HTTPS PWA 更新或浏览器打印引擎，不能仅靠 Node 脚本宣称完全验收。

这不是功能回退，而是把本地已经证明的部分和部署后必须观察的部分明确分开。

## 3. 按六阶段逐项核对

### 第一阶段：数据与可靠性底座

**状态：核心完成，外部同步和部署行为需复核。**

已完成：

- `TimeEntry.date` 成为明确的执行归属日期；计时、手动补录、完成时记录、推断记录和旧数据残余分开处理。
- `statusHistory` 与每日计划基线用于重建“截至当日”的任务状态，未来完成不会反写昨天的完成结果。
- 完成任务但没有时间记录时，统计区分真实时间、推断时间和无记录完成，不把推断分钟伪装成真实学习。
- [state-schema.ts](../src/lib/state-schema.ts) 提供 Zod 入口验证；JSON、IndexedDB 和 Supabase 数据在进入应用状态前先验证，再迁移和归一化。
- [db.ts](../src/lib/db.ts) 对损坏数据建立隔离恢复快照；迁移、替换和无效输入都保留可下载恢复副本。
- Supabase 快照增加 `revision`，上传采用条件更新；冲突时保留本地与远端状态，不静默覆盖。
- [AppErrorBoundary.tsx](../src/components/AppErrorBoundary.tsx) 提供白屏兜底、重新加载和进入恢复中心入口。
- PWA 更新改为提示式更新，完成当前输入后由用户决定刷新。

已验证的关键场景：

- 昨天未完成、今天完成：昨天仍为未完成。
- 从今天返回昨天补录：分钟归入用户选择的昨天。
- 跨日真实记录：每天分别累计，任务总实际时间为所有真实记录之和。
- 损坏顶层备份：Schema 拒绝，不进入 React 状态。

部署后仍需：配置真实 Supabase 项目，用两个浏览器会话模拟同时修改；在 HTTPS PWA 环境验证更新提示不会打断填写。

### 第二阶段：首次建档与录入效率

**状态：核心完成。**

已完成：

- 首次建档保存步骤、批次、表单草稿和最近编辑项，页面关闭后可以继续原批次。
- 空批次优先复用，避免连续创建同名空批次。
- 可用时间必须由用户明确确认，首次排期按钮才会启用。
- 录入页同时支持独立任务、任务组、自然语言输入、粘贴清单和文件导入。
- 导入支持表头映射、完整模板、固定日期/偏好日期语义、字段说明、错误行原位编辑和分页预览。
- 连续新增保留科目、预计分钟、优先级、拆分和依赖等可复用字段。
- 录入阶段只更新轻量摘要，不对每一次新增执行完整排期。
- 可拆分任务会计算真实拆分段数，导入和录入预览会直接显示预计生成数量。

运行证据：1000 项连续录入 P95 0.054ms；正式计划零改动，且没有产生排期副作用。

### 第三阶段：日常使用和手机体验

**状态：核心完成，真实设备体验需复核。**

已完成：

- 今日页突出下一项主行动，冲突、逾期、待安排和复盘入口收敛为待处理提示。
- 手机默认使用周列表；月历保留七列，但不再依赖极小文字展示全部任务。
- 任务收件箱支持待处理、未安排、逾期、今日、未来和已完成筛选。
- 任务列表提供分页式可见数量和批量完成、批量锁定、批量解锁、批量归档。
- 删除、锁定、归档等低频操作使用更紧凑的操作区，手机关键操作保留文字标签。
- Drawer、复杂弹窗和移动端全屏页面具备独立滚动、Esc/关闭路径、焦点陷阱和安全区布局。
- 375px 相关 CSS 规则已覆盖横向溢出、触控尺寸、月历七列和全屏弹窗。
- 手机端取消滑屏翻页，页面导航只通过明确的导航控件触发。

自动静态布局审计为 28 / 28。仍建议在真实 375px、390px 和桌面窄窗口打开今日、月历、统计、导出、重排和抽屉，确认浏览器字体和滚动条差异没有造成新的横向溢出。

### 第四阶段：重排与算法升级

**状态：核心搜索与量化协商完成；完整搜索策略仍有演进空间。**

已完成：

- 循环依赖检测；发现循环时不猜测顺序、不强行排期。
- 贪心候选放置后增加有预算的局部交换，尽量为未安排任务释放一个合法位置。
- 可拆分任务在建档阶段生成独立可排期学习段，并保留原始项目、段号和总段数。
- 使用 `dataRevision` 与结构化回退签名作为稳定重排缓存键；旧数据没有 revision 时也不会因相同时间戳错误复用旧结果。
- 规划、摘要和完整解释分层；复杂方案在 Worker 中计算，可以取消，不阻塞主页面。
- 500 项复杂基准 P95 31.31ms，1000 项 P95 50.18ms；同一输入结果稳定，500 项增量场景既有任务移动数为 0。
- 冲突面板支持按日期、规则和任务逐项选择一次性例外；例外可以限定临时上限、日期和受影响任务。
- 不可行场景给出“最低可行上限”等量化信息，支持本次增加分钟、改变期限、使用缓冲日或调整目标后重新预览。

本轮实际采用的是“贪心 + 有预算局部交换 + 量化协商”的稳定实现。路线文档中更高成本的独立 Beam Search、多步交换和调度阶段动态拆分，暂未作为单独算法模块继续扩张；当前已具备安全兜底，不会因为找不到位置而强塞任务。若后续继续做算法升级，应以找解率、无关移动量和 Worker 取消响应为门禁，而不是只追求更多策略名称。

### 第五阶段：统计、报告与复盘

**状态：核心完成。**

已完成：

- 今日、统计页、CSV、统计报告、任务清单长图和月历导出共用执行账本与历史状态口径。
- 统计页区分真实实际、推断时间、计划外真实执行、旧数据残余和状态估算。
- 复盘包含原计划、真实执行、跨日补做、提前执行、计划外执行、完成率、任务组趋势和时长偏差。
- 导出支持自定义日期范围、近 7/30/90 天、今天以后和完整计划。
- PDF 报告支持选择模块，包含范围概览、每日趋势、完成率、科目/任务组、目标、质量、热力图、任务清单和时间流水等模块。
- 任务清单支持自定义日期、任务、科目、预计分钟、实际分钟、进度和状态列，并生成纵向长图。
- 月历支持月份选择、月历 PDF、月历 PNG、月历 CSV；任务数量多时按任务总量自适应高度，不依赖固定小格子截断任务。
- 报告中的“无记录完成”“推断完成”“真实 + 推断”会明确标注，无法精确恢复的历史不会伪装成真实记录。

PDF 目前通过浏览器打印窗口保存为 PDF，优点是中文字体和本机打印设置由浏览器处理；上线后应在 Chrome、Edge、Safari 各抽查一次分页、页眉、页码、长表格和月历任务完整性。

### 第六阶段：架构与性能收敛

**状态：性能与按需加载门禁完成，物理拆分仍保留为后续工程债务。**

已完成：

- 统计、目标、计时器、教程、录入和导出页面按需加载。
- Vite 手动拆分图表、日期库、图标和通用 vendor chunk。
- PWA 首次预缓存排除教程大图，降低首屏离线缓存体积。
- 新增 Bundle 检查：主入口 gzip < 200KB、统计页 gzip < 100KB、首次预缓存 < 2.5MiB。
- Vitest 已覆盖执行账本、Schema、统计导出、时区和属性测试；CI 保留类型、测试、构建、Bundle 和调度性能门禁。

当前门禁测量：主入口 gzip 约 143KB；统计页 gzip 约 12KB；PWA 预缓存约 1.85MiB。

尚未完全物理拆分的部分：`AppContext` 仍是集中式领域操作入口，调度器和 CSS 仍是大文件内的逻辑分区，尚未拆成独立包；这不影响本轮功能和 Bundle 门禁，但后续重构应保持现有数据口径和测试不变。

## 5. 本轮没有漏掉但不应伪装成“自动完成”的项目

1. **真实浏览器 axe**：当前自动门禁覆盖真实组件结构和静态布局规则，但还没有在 CI 启动浏览器后逐个访问真实路由执行 axe。部署前应补 Playwright/浏览器级检查。
2. **Supabase 并发**：本地代码已采用 revision 条件更新；没有配置项目密钥时，无法在本地证明两台真实设备的网络竞态。
3. **PWA 更新**：提示组件和 `registerType: prompt` 已完成；需要 HTTPS 安装态才能验证 Service Worker 更新时机。
4. **打印 PDF 视觉质量**：PDF 由浏览器打印引擎生成，必须在目标浏览器抽查分页和中文字体，Node 构建不能代替这一检查。
5. **覆盖率阈值**：Vitest、属性测试、可注入时钟和时区测试已经存在，但本轮没有把一个过低的全局覆盖率数字强行设成门禁；后续应按调度、统计、同步三个领域分别设置分支覆盖率。
6. **完整 Beam Search 与领域物理拆分**：当前版本优先保证稳定、可解释和低延迟；完整 Beam Search、`AppContext` 领域拆包和 CSS 文件拆分属于下一轮可控重构，不应在没有基准的情况下贸然扩大改动面。
