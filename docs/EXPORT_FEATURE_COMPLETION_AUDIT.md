## PDF 排版方案

报告采用以下顺序，避免把所有指标堆成一张长表：

1. 标题、导出日期范围和统计口径说明。
2. 范围概览卡片，先回答“这段时间学了多少、计划多少、完成得怎样”。
3. 趋势图和完成率图，先看变化，再看明细。
4. 科目、时长准确度、目标和执行质量等可选分析模块。
5. “每天任务清单”，按日期卡片显示完成、部分完成、未完成。
6. 每日统计表、任务明细表和时间流水表，用于核对具体数据。

热力图已改为紧凑网格，只保留颜色密度、月份和星期信息，不再占据报告的大块纵向空间。

## 仍需注意的产品边界

- PDF 是浏览器打印生成的，不会由应用直接写入服务器；用户需要在打印窗口选择保存位置。
- 导出很长日期范围或包含大量任务时，PDF 会自然分页，PNG 会自然变高。这是为了保留完整任务信息；若以后需要分享，可以再增加“摘要版”和“完整明细版”两个预设。
- 登录入口只有在配置 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY` 后才会出现在“设置 → 账号与同步”，与导出功能本身无关。
